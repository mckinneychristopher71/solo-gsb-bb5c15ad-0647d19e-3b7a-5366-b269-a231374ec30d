折页阅读顺序校样 Fold Reading-Order Proofing

1. 行列纸格

点击画布中的纸格可编辑每片叶子的正/反面页码（留空为空白页）。

2. 添加折叠步骤

也可直接点击画布边缘的箭头。非法折线显示为红色虚线，点击会标出冲突纸格。 “向左折”指右侧纸瓣向左翻过折线，其余类推。

3. 方案存取

    第 0 / 0 步
    纸格/叠层 移动纸瓣 冲突纸格 追踪面片

    先在左侧创建行列纸格。

    折叠步骤

    1. 尚无步骤

    面片轨迹

    选择原始纸格与正/反面后，系统从第 0 步到末步生成时间线： 每一步该片所在格位、叠层中的层序、所选面朝上/朝下与正立/倒置。 点击任一节点即联动上方回放定位到该步并高亮该片；首个非法步骤会中断时间线并标明原因。

    页码朝向

    在画布里，倒排页码会旋转 180° 显示，并标注 ⟲倒。

    最终阅读顺序（封面 → 封底）

    完成折叠后在此输出页码序列。

    双面印刷版预览

    全部折叠合法并收成单叠后，按当前纸格标注并排生成正面版 / 背面版： 背面纸格按所选翻转边镜像，格内页码再按面片朝向旋转，打印后沿所选边翻面、 按既有步骤折叠时，阅读顺序与当前回放一致。

    折手自动寻路

    指定某个原始纸格的正面或反面作为最终朝上的封面，从当前方案的 末态出发搜索收成单叠的最短后续折法。仅支持不超过 4×4 的网格， 最多 8 个后续步骤、2 秒搜索上限。

    自动拼版

    全部折叠合法并收成单叠后，按封面→封底槽位连续填页码， 反向写入每个原始纸格的正/反面。预览不会改动当前标注。
